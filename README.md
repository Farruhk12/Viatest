# Viatest static website

Статический информационный сайт по Markdown-спеку `WEBSITE_SPEC_PREGNANCY_TESTS.md`.

## Запуск

Откройте `index.html` в браузере или запустите `node local-server.cjs` для локального сервера. Сайт не требует сборки или установки зависимостей.

## Структура

- `index.html` — главная страница: hero и быстрый выбор раздела.
- `calculator.html` — калькулятор даты теста.
- `tests.html` — каталог тестов и карточка продукта.
- `instructions.html` — инструкции по использованию и таймер с прогресс-кольцом.
- `results.html` — как читать результат, что делать дальше.
- `faq.html` — частые вопросы, статьи и блок доверия.
- `styles.css` — общая визуальная система для всех страниц.
- `app.js` — товары, ссылки покупки, калькулятор, таймер и события аналитики; подключается на всех страницах, каждая функция активна только там, где на странице есть нужная разметка.
- `assets/` — логотип, изображения продуктов и инструкции DOCX.

## Ссылки покупки

Все товары описаны в массиве `products` в `app.js`. Общий переход на витрину задан в `DEFAULT_BUY_URL`:

```js
const DEFAULT_BUY_URL = atob("...");
```

Когда появятся точные URL карточек товаров, замените `buyUrl` у нужного товара.
