Интерпретация

Как читать результат ХГЧ-теста

Оценивайте полосы в зоне C и T только в интервале времени из инструкции конкретного теста.

Положительный

Две розовые полосы в областях C и T означают положительный результат по инструкции ХГЧ-теста.

Отрицательный

Одна розовая полоса только в области C означает отрицательный результат по инструкции.

Недействительный

Если контрольной полосы C нет или полос нет совсем, повторите тест новым устройством.

Частый вопрос

Слабая вторая полоска

Инструкция ХГЧ-теста отмечает: при слабой тестовой полосе повторите тест с первой утренней мочой через 48–72 часа. Какой бы результат ни был получен, рекомендуется проконсультироваться с врачом.

Что делать дальше

Какой результат вы получили?

Выберите вариант, чтобы увидеть следующий безопасный шаг без постановки диагноза по внешнему виду теста.

Алгоритм

Следующий шаг после результата

После положительного результата

  1. Убедитесь, что результат оценён в нужное время и по инструкции.
  2. При необходимости подтвердите беременность медицинским методом по рекомендации врача.
  3. Запланируйте консультацию медицинского специалиста.
  4. При боли, выраженном кровотечении, обмороке или других тревожных симптомах обратитесь за медицинской помощью без ожидания планового визита.

После отрицательного результата

  1. Проверьте, не был ли тест сделан слишком рано.
  2. При необходимости повторите тест согласно инструкции.
  3. При сохраняющейся задержке обратитесь к медицинскому специалисту.
